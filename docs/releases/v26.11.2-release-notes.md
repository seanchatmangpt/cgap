## 1. Upgrade / migration guide

### riscv32imc builders

- The atomic ladder fix (ADV-11) means the platform now lands in the
  implcell arm and REFUSES loudly unless you opt in. Build with:

      RUSTFLAGS='--cfg implcell_critical_provided'

  or expect a typed refusal instead of a silent legacy-cfg slide
  (lanes/lane-r-adv11fix-implcell-slide.md:36-51,72-73). Witnessed:
  build without the flag refuses; with the flag, compiles clean.
- Default-features builds still FAIL on riscv32imc (E0463, no std
  for the target). The no_std claim holds only with
  `--no-default-features`
  (redteam/red-11-riscv-reentrancy-corruption.md:34-37;
  red-20 §0 correction 2).

### no_std consumers of the seal counter

- The seal/stamp counter path is affected by the M-CTQ consolidation
  stations: seal throughput rows 30-32 are consolidation-addendum
  class - receipted on this host only; the cross-instrument wire legs
  are UNVERIFIED (11-measured-claims.md:126-127). no_std consumers
  reading the counters via `CgasStatsBlock` get the 120 B repr(C)
  layout with CRC over bytes [0,112) (stats.rs:30-33,111-113); the
  CRC word and trailing pad are excluded from CRC coverage by design.
