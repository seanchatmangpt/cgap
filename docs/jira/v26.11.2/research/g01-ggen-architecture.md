## Sync pipeline (crates/ggen-engine/src/sync.rs, 4,600 lines)

Entry `pub fn sync(root, opts)` sync.rs:343. "Five-stage: Resolve → Enrich → Extract → Render →
Write" (sync.rs:1). CLI `ggen sync run` (verbs/sync.rs:16); bare `ggen sync` → `sync run`
(lib.rs:270, 293-294).

Stage-order nuance (flag for docs): headline 5-stage names don't map 1:1 to code's numbered
stages; OTEL span names differ again.

- **Stage 0 schema dispatch** (sync.rs:344-368): `schema_dispatch::load` classifies ggen.toml;
  declarative-rules manifests route to `generation_rules::run` (:351-356). Single dispatch
  point; six former ad-hoc call sites consolidated (BUG-005: `ggen doctor` rejected declarative
  manifests); Ambiguous/Unsupported/Malformed fail closed typed CONFIG_SCHEMA_*.
- **Stage 1 Resolve** (span pipeline.load, :370-376): read manifest + ontology, build graph
  engine, resolve packs. dry_run gates which resolver — read-only resolution fails closed
  [FM-PACK-012] on cache miss (:388-400).
- **Stage 2 Enrich** (span pipeline.extract, :634-662): every non-overlay template's
  `construct:` query once into shared graph. **Single pass, not fixed-point** — dependent
  constructs need a second sync (:4-7). rdf:/rdf_inline: templates build overlay graphs
  (:636-640).
- **Stage 2b Law** (span pipeline.validate, :664+): N3 rules, denials, SPARQL gates;
  oxigraph engine refuses law inputs [FM-LAW-*] (:666-669). Gates evaluate in sorted filename
  order (:813-814, 875, 1987-1988).
- **Stage 2c EA Graph/depgraph admission** (:1007-1095): pack DAG/cycle/port admission,
  ea.graph.json SBB admission, receipt-generation lease gate (:983-986), CapTable extraction
  (:1097-1111).
- **Stages 3-4 Extract+Render** (span pipeline.generate, :1113-1124): all templates rendered
  in memory BEFORE any write — render failure on template N leaves no partial disk state.
- **Stage 5 Write** (span pipeline.emit, :1649-1655): **not transactional**; mid-loop I/O
  failure still receipts before erroring (red-team F1, :1657-1667).

## Determinism / byte-identical replay

- Receipt chained over {graph_hash, outputs: path→BLAKE3}, ts_ns fixed to 0 (:10-19).
- BTreeMap/BTreeSet everywhere (:24, 233-315, 1153); templates enumerated sorted (:2622);
  globs sorted (:813-814, 2037).
- graph_hash = BLAKE3 of post-Enrich canonical graph; input closure maps every input file →
  BLAKE3 with `actuator` entry naming generator version; unreadable inputs recorded MISSING
  (:237-242); editing a declared rule file changes the receipt even when outputs unchanged
  (:134-137).
- Engines: default GraphLaw (praxis-graphlaw, N3/Datalog materialization + SHACL/ShEx gates);
  Oxigraph kept for A/B determinism testing (:61-70).
- Replay: crates/ggen-engine/src/replay.rs — GALL-001 clean-state replay: clear prior
  consequences, re-run sync, compare source/reconstructed/replayed receipt SHA-256; status
  always "PASS" on Ok (:15-34, 256-302); requires existing portable receipt else [FM-CHAIN-16].
- CLI honesty: dry-run renames `written` → `planned_writes` + `dry_run: true` at verb layer;
  engine SyncReport still serializes `written` (verbs/sync.rs:19-35).
