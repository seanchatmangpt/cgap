# pub-05-new-api-surfaces

PUB-05 new API surface audit (2026-11-02, read-only; counts from
live src scans). Scope: cgap-git (15 lane modules), cgap-storage
(dred publics), cgap-core (checkpoint.rs), cgap-parquet.

## 0. Headline findings

1. cgap-core/src/checkpoint.rs NOT exported (lib.rs = 3 lines:
   dma_ring/frame/isomorphism); reached only via #[path] in
   tests/checkpoint_court.rs:13. tracking_alloc also unexported
   (exempted tracking_alloc.rs:49). Deliberate (E0152).
2. cgap-parquet/src/generated_compiled_manifest.rs mounted
   NOWHERE — dead file whose pub const collides by name with the
   live compiled_manifest table, carrying a lying "GENERATED by
   ggen" banner. Delete or mount-and-dedupe before publish.
3. cgap-storage and cgap-core have NO #![no_std] attribute;
   several modules claim "no_std-ready" in docs — aspirational,
   not real.
4. Absolute filesystem paths leak into crate docs:
   cgap-parquet/src/compiled_manifest.rs:7
   (/Users/sac/ggen-marketplace/...) and rle.rs:582
   (/Users/sac/cgap/...).
5. cgap-git/src/dag.rs:120-121 mounts pack.rs as PUBLIC
   cgap_git::dag::pack via #[path] with an in-doc confession the
   correct path (crate::pack) is a pending one-line edit — a
   stable-API liability pre-publish.
6. Internal jargon floods public docs: "court" 104x in cgap-git
   src, 99x parquet, 44x storage, 27x core; lane/receipt
   citations in crate docs of all four crates.

## 1. cgap-git — 15 new lib-mounted modules (lib.rs:146-162)

All pub mod, every pub item documented (zero undocumented found),
#![no_std] + forbid(unsafe_code) (lib.rs:9-10), default "std".
Each carries its court test. 183 new pub items total; zero leaks.
Prior modules (deflate/inflate/pack_write) use alloc Vec in pub
signatures — acceptable under extern crate alloc; pack_write
spells alloc::vec explicitly, deflate doesn't (cosmetic).

## 2. cgap-storage — dred publics + crate-mates

Crate NOT no_std (no attribute; std by implication). 89 pub
items. dred (16, docs OK; std confined to cfg(test) courts),
atomic_commit (62, honestly discloses pending attrs), bitplane
(4), closure (7 — std BTreeSet in pub signature, disclosed).
Debts: bitplane_seen.rs:57-58 unsafe std::alloc::alloc_zeroed
with NO SAFETY comment + :59 pub Box in a no_std-claiming
module; dred.rs:7 cites a nonexistent "crate attribute pattern";
lib.rs:1 "PROPOSED scaffold" as the whole crate description.

## 3. cgap-core — checkpoint.rs status

Verified UNEXPORTED (grep clean). Dormant publics: 5 items, all
documented, no_std-clean (fixed buffers + fn-ptr digest
injection). Header docs cite internal lane receipts — would
surface on crates.io docs if mounted verbatim. Crate-mates
clean except lib.rs:1 "PROPOSED" + dma_ring internal spec cites.

## 4. cgap-parquet

#![no_std] with alloc + cfg(std). 21 pub modules + 1 pub use.
std leaks in pub APIs are ALL inside #[cfg(feature = "std")]
items — clean gating. Debts: mmap_writer.rs:752 SpillSync trait
undocumented; compiled_manifest.rs:7 + rle.rs:582 absolute
paths; generated_compiled_manifest.rs dead/colliding.

## 5. Crates.io embarrassments (consolidated)

1. compiled_manifest.rs:7 absolute path (username visible).
2. rle.rs:582 absolute path (repo layout disclosed).
3. patent_court.rs:3-9 — public module citing internal patent
   receipts + legal-strategy prose ("statutory numbers",
   exit-101-class). Publishing a module named patent_court with
   legal-strategy docs is a disclosure risk beyond aesthetics.
4. storage lib.rs:1 / core lib.rs:1 — "PROPOSED scaffold" as
   the crate description.
5. git lib.rs:1-7 — internal ticket path citation.
6. generated_compiled_manifest.rs — dead GENERATED file shipping
   in the source tree.
7. Court jargon (104/99/44/27 mentions) — incomprehensible
   externally without the internal glossary.
8. dag.rs:120-121 stopgap public #[path].
9. bitplane_seen.rs:18 no_std claim vs :57 std::alloc unsafe.

## 6. Documentation debts (file:line)

mmap_writer.rs:752 SpillSync trait doc; compiled_manifest.rs:7 +
rle.rs:582 absolute paths; bitplane_seen.rs:57 SAFETY + :18
false no_std claim; dred.rs:7 nonexistent pattern cited;
storage lib.rs:1 + core lib.rs:1 PROPOSED docs; git dag.rs
:115-121 stopgap; patent_court.rs:3-9 internal receipts;
generated_compiled_manifest.rs:1 dead file. Overall: doc
coverage excellent (1 undocumented item across ~370 publics);
debts are qualitative — paths, jargon, no_std claims vs reality.
