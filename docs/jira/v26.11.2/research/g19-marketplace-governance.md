## Pack contract (what a consumer resolves)

- pack.toml [pack]: name (=dir name), version (SemVer), description; only admitted keys
  {name, version, description, deprecated, superseded_by} (PACK_TABLE_KEYS marketplace.py:87;
  unknown keys refused :366). Loader-level deny_unknown_fields — arbitrary extension keys
  break the real ggen loader (pack-contract.md:15).
- [capabilities]: provides/requires/types sorted-deduped BTreeSet<String>; self-IRI invariant
  urn:ggen:pack:<pack-id> in provides, globally unique.
- Composition: `ggen pack compose` topologically orders by capabilities.requires (order-only,
  cycles dropped deterministically, never refuse); only manifest `dependencies` edges refuse —
  four refusal classes DuplicateCapability, UnboundRequirement, DuplicateArtifactPath,
  CyclicDependencies (README.md:99-108).

## Versioning / release governance

- Per-pack SemVer; bump when "published behavior or contract changes"
  (update-a-pack.md:22).
- Release gate (release-check, marketplace.py:575-597): version must be vYY.M.P; releases
  immutable (RELEASE_TAG_EXISTS → bump [marketplace].version); monotonic
  (RELEASE_VERSION_NOT_MONOTONIC); CONTENT_CHANGED_WITHOUT_VERSION_BUMP fires when pack
  content changed by git tree identity without a version bump (:532-557).
- Consumer locking: scripts/fetch_pack.py — lock → packs.lock.json (name, version, sha256
  digest, download_url) committed in the consumer repo; verify recomputes archive sha256
  (REFUSED:DIGEST_MISMATCH, exit 2); fetch downloads, verifies against lock AND catalog
  (REFUSED:LOCK_CATALOG_DRIFT), extracts with path-safety refusals (REFUSED:UNSAFE_PATH,
  LINK_MEMBER, SPECIAL_MEMBER, OUTSIDE_PACK_ROOT) — pin-and-verify-packs.md:1-36.
- Marketplace's own ggen.lock: single entry mdbook-pattern-language-pack (dogfood only).

## Deprecation / lifecycle

- lifecycle.toml, schema_version "1.0.0" (:6); lives outside pack.toml because the loader
  denies unknown [pack] keys (pack-lifecycle-registry.md:5). Missing file = empty registry,
  not error.
- Two independent axes (:28-47): state = active / deprecated (resolvable, discouraged) /
  superseded (named successor fully covers it; kept for path-pinned consumers) / retired
  (removed from discovery, bytes kept); intent (advisory) = consolidate / keep-separate /
  replace / upgrade / review. state=active with no intent refused (LIFECYCLE_ENTRY_EMPTY).
- Full REFUSED:LIFECYCLE_* table (~20 codes) :51-74 — successor-must-exist,
  successor-must-be-live, reason mandatory, since must be vMAJOR.MINOR.PATCH, evidence paths
  must exist, LIFECYCLE_MANIFEST_CONFLICT when pack.toml legacy keys contradict registry.
- Fallback ordering: registry entry wins; legacy pack.toml deprecated/superseded_by honored
  only when no registry entry (:77; resolve call marketplace.py:139-142).
- Procedure ladder ("choose the smallest truthful flag"): flag-a-pack-lifecycle.md:5-18.
  Deprecation law: "Deprecation must name a successor and preserve migration/compatibility
  evidence rather than silently deleting historical consumers" (README.md:185). Real example:
  clap-noun-verb-pack deprecated with 6 named successors, since v26.8.19
  (lifecycle.toml:8-17).

## Consumer-side declaration (ggen.toml [packs])

- **Form A — table of inline tables** (documented convention):
  `[packs]` / `hello-pack = { path = "../pack" }` (examples/hello-pack/consumer/ggen.toml:7-8;
  same at ggen-marketplace/ggen.toml:6-8 with quoted hyphen keys). Required context keys:
  [project], [ontology] (source), [templates] dir (consume-a-pack.md:14).
- **Form B — array of tables with registry tag** (only in solutions/ + fixtures):
  `[[packs]] name="aaif-vanilla-pack" registry="local" path=...`
  (solutions/enterprise-aaif/ggen.toml:16-24). Verify against the ggen loader before
  documenting as canonical.
- Consumer workflow (consume-a-pack.md): reference by path (:7-14) → record marketplace
  revision (git rev-parse HEAD) + ggen --version (:18-19) → remote consumption via
  `marketplace.py catalog --scope all` for archive URL+digest, verify digest BEFORE extraction
  (:22-28) → verify behavior with native tests, replay via second sync byte-compare, ggen
  receipt verify (:32) → **authority boundary**: manufacture is CONSTRUCT; never infer
  execution authority from pack publication, catalog membership, or qualification (:36-40).
