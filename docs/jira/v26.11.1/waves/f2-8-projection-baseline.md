## Divergences and notes

- Replay runs in a /tmp sandbox rather than the charter's in-place
  "run + byte-compare vs HEAD + restore" fallback — strictly stronger:
  the shared tree is never touched, so there is no restore window to
  fail closed on. The court still exercises sha256-exact restore with
  mtime bump inside the sandbox, per dispatch contract.
- The 12 modified tracked files in the worktree (in-flight lanes) are
  all hand-authored lane code; none is in the declared generated set,
  so the baseline is not skewed by them.
- tracked_bytes drifts a few KB between runs (concurrent lanes on the
  shared checkout); the receipt number is as of the witnessed run.
- ggen 26.10.11 was the replay engine identity for every run.
- CLAUDE.md row paths mix two anchors (brace-expanded tokens carry
  `crates/cli/` prefix, siblings are cd-relative); the instrument
  resolves this by tracked-existence and records the reading — future
  graph-projected tables should emit one anchor.
- Sandbox debris: all gate-run sandboxes are rmtree'd in `finally`;
  three debug sandboxes created during iteration were removed.
