## Drift detection (four layers)

1. **Pack lock drift (fail closed)**: `check_lock()` — on-disk BLAKE3 differs from locked
   hash → refuse `[FM-PACK-008]` naming old/new hashes; malformed lock `[FM-PACK-009]`.
   Missing lockfile OK (first sync); packs absent from lock OK (locked next sync).
   pack.rs:1329-1375; invoked sync.rs:405-406.
2. **Per-output content drift**: identical → `Skipped("unchanged: content identical")`
   (checked before the force arm — TECH-DEBT-003 fix) write.rs:191-193; differing content
   without force: true → `[FM-WRITE-005]` "refusing silent clobber" (:201-208). Dry-run
   mirrors exactly (sync.rs:2518-2531).
3. **Freeze drift**: freeze_policy always + differing candidate → `DRIFT:` reason (file never
   overwritten); freeze_policy checksum stores BLAKE3 per file, flags manual edits
   (write.rs:247-302, DRIFT text :263-268). DRIFT-bearing decision quarantined in receipt as
   Fail+Quarantined with obligation `FROZEN-DRIFT:<path>` (sync.rs:3786-3812).
4. **Receipt closure drift**: `compare_closure_class()` diffs this run's {key → blake3}
   input-closure submap vs previous receipt (source/config classes), naming
   added/removed/changed keys (sync.rs:3468-3504, consumed :4150-4151). Stale-epoch guard:
   REFUSED_STALE_LEASE when run generation ≤ target's persisted lease baseline
   (sync.rs:1596-1624; write.rs:141-148).

## Byte-identical replay

- Producer side: every sync chains a ReceiptRecord over {graph_hash, outputs:{path→BLAKE3}}
  into `<root>/.ggen-v2/receipt.json`, ts_ns fixed 0 (sync.rs:11-21). Replay court
  (replay_court.rs) re-hashes every bound consequence on disk: REPLAY_ABSENT /
  REPLAY_MISMATCH / REPLAY_UNREADABLE; only ALIVE envelopes promote to PASS
  (replay_court.rs:104-202, consts 28-34).
- Determinism recheck: `determinism: true` frontmatter runs extraction against a genuinely
  independent second graph load (fresh engine, Turtle re-read) to catch load-time
  nondeterminism (sync.rs:1157-1241, second-load builder :3138-3190).
- Consumer side (cgap gate0): `make gate0` runs `ggen sync run` twice, sha256's the four
  generated surfaces each run, `cmp` the two digest files — byte-stable replay proof, then
  freestanding C-header compile (/Users/sac/cgap/Makefile:42-54, GATE0_FILES :34-37).

## Post-processing hooks (the manifest_patch.py slot)

ggen has no manifest_patch mechanism; nearest equivalents are per-template `sh_before`/
`sh_after` shell hooks (denylist-checked, sh -c, cwd = project root, non-zero = hard error;
sh_after fires only on Written/Injected) — sync.rs:2559-2619; dry runs never execute hooks
(:2513-2516).

cgap's `manifest_patch.py` is consumer-owned, run manually post-sync
(crates/cli/manifest_patch.py:1-57): the six-pack generates a standalone Cargo.toml;
FM-PACK-018 mandates crate-pack, FM-WRITE-008 forbids a consumer template targeting the same
file, FM-WRITE-005 makes re-sync refuse a patched manifest — hence patch lives post-sync and
is **idempotent** (no-op when cgap-arrow present and [patch.crates-io] exists; asserts anchor
`blake3 = "1.8"` to detect manifest shape drift, :38-51). Adds 13 kernel path deps + the
`~/clap-noun-verb` patch section.
