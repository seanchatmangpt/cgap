## 4. ANALYSIS (labeled)
Distinct engineering disciplines this represents:
1. **Pool-leased allocation** — per-thread lease slots pre-open the spill handle and mint the ring once at grant; steady-state commits never touch File::create or the allocator (sovereign.rs COMMIT_LEASE). Allocation is provisioning-phase, not steady-state.
2. **Spill-on-rotation durability** — the durability boundary sits at ring rotation via a trait seam, with the residual undrained window declared in source, plus honest labelling (STAGED != DURABLE).
3. **Typed capacity refusal** — noalloc.rs and BitPlaneSeenSet return typed errors at capacity instead of heap-growth fallback or silent truncation; capacity is a law callers design against.
4. **Stack-frame budgeting** — two witnessed overflow classes (16 MB stack-staged box; multi-MiB noalloc debug frames) drove a structural fix (allocate-at-the-allocation) and a venue fix (dedicated thread). "Where does this value materialize" is treated as first-class.
5. **Allocator reentrancy avoidance** — F1's repair-08 is the textbook trap: anything inside a GlobalAlloc method that can allocate (eprintln! stdio, thread::current() TLS fallback) recurses into the allocator being implemented; two independent witnesses in one lane. The landed playbook (no alloc inside the allocator, post-disarm-only diagnostics, stack-pointer instead of thread handles, saturating disarm, serve-real-memory over panic/null) is each derived from a measured failure, not folklore.
6. **Fail-closed court design (unifying)** — every gate cited (linker ASSERTs, budget script, alloc courts, spill gate) carries an anti-vacuity leg that must flip or the court self-declares FAIL; budgets without demonstrated refusal paths are decoration.

Gaps: "48,152-class" charter figure matches no landed artifact (49152 is real); D21 records gate coverage is entry-surface-only, so "the engine fits" remains probe-derived, not gate-enforced.
